# 文章

用 GitHub Pages 發布的公開文章：https://koalbert.github.io/notes/

## 新增一篇文章

1. 建一個新目錄（英文小寫、用 `-` 連接，例如 `newton-method/`），文章放在裡面的 `index.html`。
   可以複製 `power-to-log/index.html` 當範本，共用 `assets/style.css`。
2. 在根目錄 `index.html` 的清單最上面加一行連結。
3. commit、push，約一分鐘後網址 `https://koalbert.github.io/notes/<目錄名>/` 就會更新。
