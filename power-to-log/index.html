從「次方」一路走到「Log」

2026-10-03

前言：一題帶你走完四個觀念

這篇文章用第 5、6 題當主線，帶你從「次方」一路理解到「log」，最後算出答案 k = 1。重點不是背公式，而是看懂每條公式是怎麼「長出來」的。

題目是這樣的：已知 a > 0，且 a^(3x/2) = 8（第 5 題）。第 6 題要把 a^(50x) 寫成科學記號 b × 10^n（1 ≤ b < 10，n 為整數），並且已知 k ≤ b < k + 1，求 k。

我們會依序經過四站：

  1. 次方：乘法的簡寫，以及它的基本規則

  2. 分數次方：為什麼 1/2 次方就是根號

  3. 對數 log：反過來問「幾次方」

  4. 科學記號：用 log 找出一個超大數字的「開頭」

第一站：次方就是「乘了幾次」

所有次方規則，都來自一個最簡單的定義：2^3 就是 2 自己乘 3 次。

2^3 = 2 \times 2 \times 2 = 8

只要記住「指數 = 乘了幾次」，下面四條規則都能自己推出來。

規則 1：同底數相乘，指數相加

a^m \times a^n = a^{m+n}

例如 2^3 × 2^4：前面有 3 個 2，後面有 4 個 2，全部攤開共 7 個 2，所以等於 2^7。乘的次數直接合併。

規則 2：同底數相除，指數相減

\frac{a^m}{a^n} = a^{m-n}

例如 2^5 ÷ 2^3：分子 5 個 2、分母 3 個 2，上下約掉 3 個，剩下 2^2。所以 5 − 3 = 2。

規則 3：為什麼 a^0 = 1？

任何數除以自己都等於 1，所以 a^3 ÷ a^3 = 1。但用規則 2 算，它又等於 a^(3−3) = a^0。兩種算法結果必須一樣，因此：

a^0 = 1 \quad (a \neq 0)

規則 4：次方的次方，指數相乘

(a^m)^n = a^{mn}

例如 (2^3)^4 就是 4 個 2^3 相乘，指數是 3 + 3 + 3 + 3 = 12，所以等於 2^12。重複 n 次相加，就是乘以 n。

這條規則第 6 題會用到：(a^x)^50 = a^(50x)

第二站：分數次方為什麼是根號？

a^(1/2) 不是「乘半次」——它是為了讓指數規則繼續成立，才被定義成 √a。

想想看：如果規則 4（次方的次方）要對分數也成立，那麼 a^(1/2) 平方之後應該是：

\left(a^{1/2}\right)^2 = a^{\frac{1}{2} \times 2} = a^1 = a

「平方之後等於 a 的正數」是誰？就是 √a。所以：

a^{1/2} = \sqrt{a}

同樣的道理推廣下去：

a^{1/n} = \sqrt[n]{a}, \qquad a^{m/n} = \left(\sqrt[n]{a}\right)^m

口訣：分母管開根，分子管次方。例如：

8^{2/3} = \left(\sqrt[3]{8}\right)^2 = 2^2 = 4

先把 8 開立方得到 2，再平方得到 4。這個例子馬上就會用到。

第三站：從第 5 題得到 a^x = 4

第 5 題的關鍵結果是 a^x = 4，而第 6 題的 a^(50x) 可以化成 2^100。

步驟 1：求 a^x

已知 a^(3x/2) = 8。把左邊看成「a^x 的 3/2 次方」（規則 4 反過來用）：

\left(a^x\right)^{3/2} = 8

兩邊同取 2/3 次方，因為 (3/2) × (2/3) = 1，左邊剛好只剩 a^x：

a^x = 8^{2/3} = 4

重點：a^x = 4 是第 6 題最重要的起點。我們不需要知道 a 和 x 各自是多少，只要整包 a^x 就夠了。

步驟 2：把 a^(50x) 化簡

再用一次規則 4，把 a^(50x) 拆成 (a^x)^50，然後代入 4：

a^{50x} = \left(a^x\right)^{50} = 4^{50} = \left(2^2\right)^{50} = 2^{100}

現在問題變成：2^100 寫成科學記號，前面的數字 b 是多少？ 2^100 大到無法直接算，這時就需要 log 出場。

第四站：Log 就是「反過來問指數」

log N 問的是：「10 的幾次方會等於 N？」它不是新的運算，而是次方的反方向。

Log 的定義

我們知道 10^3 = 1000。反過來問「10 的幾次方等於 1000？」答案是 3，寫成 log 1000 = 3。底數是 10 的對數叫「常用對數」，底數 10 通常省略不寫。

\log b = c \iff 10^c = b

為什麼 log(ab) = log a + log b？

這條公式其實就是規則 1（同底數相乘，指數相加）換個說法。設：

\log a = x \Rightarrow a = 10^x, \qquad \log b = y \Rightarrow b = 10^y

兩式相乘，依照規則 1：

ab = 10^x \times 10^y = 10^{x+y}

所以「10 的幾次方等於 ab？」答案是 x + y，也就是：

\log(ab) = x + y = \log a + \log b

log 會把「乘法」變成「加法」——因為次方相乘時，指數本來就是相加。

為什麼 log(a^n) = n log a？

a^n 就是 n 個 a 相乘，用上面的乘法公式拆開，就是 n 個 log a 相加：

\log(a^n) = \underbrace{\log a + \log a + \cdots + \log a}_{n \text{ 個}} = n \log a

口訣：指數可以搬到 log 前面。第 6 題會直接用到這條。

第五站：科學記號和 log 怎麼接起來？

一個數取 log 之後，整數部分決定 n（有幾位數的量級），小數部分決定 b（開頭的數字）。

任何正數都能寫成科學記號：

N = b \times 10^n \quad (1 \le b < 10,\ n \text{ 為整數})

兩邊取 log，用乘法公式拆開，再用 log(10^n) = n：

\log N = \log b + \log(10^n) = n + \log b

因為 1 ≤ b < 10，所以 log 1 ≤ log b < log 10，也就是：

0 \le \log b < 1

log b 一定是個「0 點多」的小數。所以只要算出 log N，把它拆成「整數 + 小數」：

  • 整數部分 → 就是 n

  • 小數部分 → 就是 log b，再用它反推 b

例如 log N = 30.103，就拆成 30 + 0.103：n = 30，log b = 0.103。

終點：完整解出第 6 題

答案是 k = 1，因為 2^100 ≈ 1.27 × 10^30。

步驟 1：取 log。 我們已經知道 a^(50x) = 2^100，用「指數搬到前面」：

\log(2^{100}) = 100 \log 2 \approx 100 \times 0.30103 = 30.103

步驟 2：拆成整數 + 小數。 30.103 = 30 + 0.103，所以 n = 30，log b = 0.103。

2^{100} = 10^{30.103} = 10^{0.103} \times 10^{30}

步驟 3：判斷 b 的範圍。 不用算出 10^0.103 的精確值，只要跟已知的 log 比大小：

\log 1 = 0 \;\le\; 0.103 \;<\; 0.301 \approx \log 2

所以 1 ≤ b < 2。（用計算機驗證：10^0.103 ≈ 1.27。）

步驟 4：對照題目。 題目說 k ≤ b < k + 1，而 1 ≤ 1.27 < 2，所以：

2^{100} \approx 1.27 \times 10^{30}, \qquad k = 1

小發現：n = 30 也告訴我們，2^100 是一個 31 位數。

公式總整理

整條路線只有一個核心：log 的規則，就是指數規則倒過來寫。

用途公式一句話理解
同底數相乘a^m × a^n = a^(m+n)乘的次數合併
同底數相除a^m ÷ a^n = a^(m−n)上下約掉相同的因數
次方的次方(a^m)^n = a^(mn)重複 n 次，所以乘 n
零次方a^0 = 1（a ≠ 0）自己除以自己
分數次方a^(1/n) = ⁿ√a讓指數規則保持一致
一般分數次方a^(m/n) = (ⁿ√a)^m分母開根，分子次方
Log 定義log b = c ⇔ 10^c = b反過來問指數
Log 乘法log(ab) = log a + log b乘法變加法
Log 次方log(a^n) = n log a指數搬到前面
常用對數log(10^n) = nlog 和 10^x 互為反運算
科學記號N = b × 10^n，1 ≤ b < 10n 決定量級，b 決定開頭

一句話記住 log

看到 log N，就先問自己：「10 的幾次方會等於 N？」 例如 log 1000 = 3，因為 10^3 = 1000。抓住這個想法，其他 log 公式都能自己推回來。
